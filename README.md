A **modern and responsive landing page** inspired by **LAMY writing instruments**, built using **HTML and CSS**.

This project demonstrates **clean UI design, responsive layouts, CSS Flexbox/Grid usage, and modern web styling**.

---



# 🚀 Features

✨ Clean modern UI
✨ Fully responsive layout
✨ Flexbox and CSS Grid layout
✨ Product showcase section
✨ Category browsing section
✨ Newsletter subscription UI
✨ Structured footer with links
✨ Tablet and mobile responsive design
